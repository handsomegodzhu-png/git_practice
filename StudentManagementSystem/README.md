# 学生成绩管理系统

## 项目简介

这是一个使用 C++ 编写的学生成绩管理系统，用于练习 C++ 基础语法、面向对象编程、STL 容器以及文件读写操作。

## 已实现功能

- 学生信息录入
- 查询学生信息
- 修改学生成绩
- 按总成绩排序
- 学生数据文件读写
- 菜单循环操作

## 使用技术

- C++
- STL 容器与算法
- 文件输入输出
- Git 与 GitHub 版本管理
